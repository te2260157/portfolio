Robot Path Finding

스택과 리스트 자료구조를 활용한 로봇 경로 탐색 프로젝트

Project Overview

로봇이 목적지까지 이동하기 위한 경로 탐색 알고리즘을 구현한 프로젝트입니다.
자료구조의 이해와 알고리즘 사고력을 키우는 것을 목표로 제작했습니다.

Technology

Python
List
Stack
Algorithm

Implementation

스택 구조를 활용하여 탐색 과정을 관리하고, 리스트 자료구조를 통해 이동 경로와 방문 정보를 처리했습니다.

Result

자료구조와 알고리즘 개념을 실제 문제 해결 과정에 적용하며 효율적인 탐색 방법을 학습했습니다.
