PROJECT 04

Embedded System

Arduino와 Raspberry Pi 기반 임베디드 시스템 프로젝트

Project Overview

마이크로프로세서를 활용하여 센서 데이터를 처리하고 하드웨어를 제어하는 임베디드 프로젝트입니다.

Technology

Arduino
Raspberry Pi
Sensor
IoT

Implementation

센서 데이터를 수집하고, 프로그램을 통해 데이터를 처리하여 하드웨어 동작을 제어하는 구조를 학습했습니다.

Result

소프트웨어와 하드웨어를 연결하는 임베디드 시스템 개발 경험을 쌓았습니다.
